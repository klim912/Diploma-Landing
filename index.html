Relevance

Why Does This Matter?

The video game market is one of the fastest-growing segments of the digital economy. According to analysts, its volume will exceed $200 billion by 2026, with the share of digital sales continuing to grow annually.

Modern players expect a convenient, fast and secure service with support for various payment methods, personalized recommendations and instant delivery of digital content.

This thesis aims to research and implement the full development cycle of such a service — from architecture design to deployment and testing.

Goals

Research Goals & Objectives

Develop and document a fully functional web application for selling video games that meets modern quality standards.

01

Architecture Design

Development of a scalable client-server architecture based on React + Firebase with clear separation of concerns.

02

Payment Integration

Implementation of secure payments via Stripe and PayPal with support for various transaction methods and user data protection.

03

Authentication & Security

Implementation of an authorization system on Firebase Auth with bot protection via Google reCAPTCHA and sensitive data encryption.

04

Testing & Quality

Three-level testing: unit tests (Vitest), end-to-end (Playwright) and BDD scenarios (Cucumber).

05

UX & Accessibility

Responsive interface with animations, multilingual support and compliance with accessibility standards.

Methodology

Research Methods

🔬

Analysis of Existing Solutions

Comparative analysis of leading platforms (Steam, Epic Games, GOG) to identify best practices and functional requirements.

🏗️

Component-Based Development

Application of component-oriented development methodology on React with a clearly defined hierarchy and code reuse.

🧪

Test-Driven Approach

TDD practices with Vitest for unit tests, Playwright for E2E and Cucumber for BDD scenarios based on user stories.

🚀

CI/CD & DevOps

Automated deployment via Firebase Hosting with version control following the Release Flow strategy.
